IMPORTANT IMAGE NAMING:
The home page highlights images/photo32.jpg through images/photo36.jpg.
The Memory Wall checks photo1.jpg through photo200.jpg automatically and only displays files that exist. So photo32.jpg, photo33.jpg, photo34.jpg, etc. will be found.
All image files should be directly inside the images folder and use the .jpg extension. If your photos are .JPG, Windows often treats this the same locally, but for hosting it is safest to use consistent lowercase .jpg names.

The CSS is designed so page content stays visible even if JavaScript fails. Animations are enabled only after JavaScript starts.
